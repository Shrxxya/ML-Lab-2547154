def compute_cost(X, y, theta):
    m = len(y)
    predictions = X.dot(theta)
    cost = (1/(2*m))*np.sum((predictions-y)**2)
    return cost

The cost function calculates the prediction error of the model.

It uses Mean Squared Error divided by two Lower cost values indicate better model performance. Gradient Descent aims to minimize this cost function.

def gradient_descent(X, y, theta, learning_rate, iterations):
    m = len(y)
    cost_history = []
    for i in range(iterations):
        predictions = X.dot(theta)
        gradients = (1/m) * X.T.dot(predictions-y)
        theta = theta - learning_rate * gradients
        cost = compute_cost(X, y, theta)
        cost_history.append(cost)
    return theta, cost_history

Gradient Descent updates the model parameters iteratively. During each iteration: Predictions are calculated. Gradients are computed. Model parameters are updated. The cost value is stored. The process continues until the specified number of iterations is completed.

The cost decreases rapidly. If the graph remains smooth, convergence is fast. If the graph oscillates or increases, the learning rate is too high, causing instability.

Convergence A very small learning rate (0.001) converges slowly. A moderate learning rate (0.01) converges smoothly and is generally a good choice. A larger learning rate (0.1) converges much faster but may overshoot or become unstable depending on the dataset.
